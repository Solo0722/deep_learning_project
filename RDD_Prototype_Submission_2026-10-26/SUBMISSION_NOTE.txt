I am submitting a working prototype of online class-adaptive local augmentation for full-image road-damage detection. The package contains the controller, training and validation scripts, tests, frozen configurations, and debugging evidence. Four 20-epoch comparisons are complete: identity, fixed image-level, fixed local, and online shared local augmentation. The online shared run achieved 23.059 validation AP50:95 versus 22.823 for identity. These are single-seed validation measurements, not a confirmed improvement. The class-adaptive implementation passed 81 local tests and an actual-model synthetic CPU integration check. Its CCAST run has started, but its final detection results are not included. Please start with README.md for the comparison table and evidence locations.
